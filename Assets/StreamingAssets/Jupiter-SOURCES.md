# Jupiter
NASA Visualization Technology Applications and Development (VTAD), Jupiter 3D Model: https://science.nasa.gov/resource/jupiter-3d-model/
Source GLB: Jupiter_1_142984.glb, SHA-256 8edc4e9b88b73ca1b125a258f0ecaef7fc6494a7cadda37704af459a119f4870.
The player uses the extracted position, normal, UV, index data and original embedded PNG atlas. Runtime converts axes/winding, normalizes radius and converts the UV V axis without reprojecting the image. NASA does not endorse this game.
